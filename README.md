# solid-doodle

**One client. Every model. Including Claude Opus.**

Unified multi-model AI client that gives you access to Claude Opus, GPT, Gemini, Grok, DeepSeek and 100+ models in a single clean interface.

### What’s included
- Mid-conversation model switching
- Side-by-side comparison of answers
- Native Claude Code & MCP support
- BYOK (Bring Your Own Key) + local models
- Transparent cost tracking
- Beautiful and fast interface
